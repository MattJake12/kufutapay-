### A Próxima Geração de Pagamentos para Comerciantes em Angola 🇦🇴

PayService+ é um MVP de uma plataforma fintech ultra-moderna, focada na experiência do utilizador e na segurança transacional. Com uma interface **Glassmorphism** de alta fidelidade, o projeto foi desenhado para facilitar a vida de pequenos e médios comerciantes no mercado Angolano.

---

## ✨ Funcionalidades Principais

- 🚀 **Onboarding Perfeito**: Fluxo de cadastro em passos com validação de PIN unificada e teclado numérico customizado.
- 📱 **Terminal POS Virtual**: Interface de vendas rápida e intuitiva.
- 💸 **Transferências Ágeis**: Envio de valores otimizado para o dia-a-dia.
- 🛡️ **Validação de Comprovativos**: Sistema de verificação de autenticidade por código único (Inspirado em normas como BAI Directo / MC Express).
- 📊 **Gestão de Crescimento**: Gráficos e metas para o comerciante acompanhar o seu desempenho.
- 🌑 **Dark Premium Core**: Design moderno focado na redução de fadiga visual e economia de bateria.

---

## 🛠️ Stack Tecnológica

- **Frontend:** React 18 com Vite
- **Estilização:** Tailwind CSS (Arquitetura Utilitária)
- **Animações:** Framer Motion (Transições de página e feedbacks táteis)
- **Ícones:** Lucide React (Consistência e leveza)
- **Estado Global:** React Context API

---

## 🚀 Como Iniciar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/MattJake12/payservice.git
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**
   ```bash
   npm run dev
   ```

## 🎨 Filosofia de Design (UI/UX)

O PayService+ não é apenas uma ferramenta, é uma experiência. Utilizamos:
- **Glassmorphism:** Camadas de vidro e desfoque para profundidade.
- **Micro-interações:** Vibração no erro, animações de entrada e feedbacks visuais instantâneos.
- **Mobile-First:** Desenhado para caber na mão do comerciante, com botões de fácil alcance.

---

## 🇦🇴 Feito para Angola
Diferente de soluções genéricas, o PayService+ inclui:
- Formatação de moeda nativa (**Kz**).
- Verificação de códigos de transferência seguindo padrões locais.
- Interface otimizada para terminais POS android (Sunmi, etc).
